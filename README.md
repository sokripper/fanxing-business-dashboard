# 梵行经营看板 · 会议版

用于确认经营看板的展示内容、计算口径和交互。包含销售、项目健康、公司经营三个板块，以及月份区间 / OP 组织筛选。

**全部是模拟数据，不连接飞书，不含会议原文、真实财务或人员数据、访问凭证。** 模拟覆盖 2026 年 1—9 月，默认展示 9 月完整月末场景，并非实时经营情况。

## 打开页面

下载或克隆仓库后，直接使用现代浏览器打开 `index.html`。无需登录，也无需安装依赖。GitHub 仓库页面显示的是代码，不会自动变成在线网站；本次没有启用 GitHub Pages 或其他公网部署。

## 文件与维护

- `meeting-dashboard.html`：可编辑源代码，包含界面、模拟数据和计算函数。
- `index.html`：可独立打开的导出页面，保留原预览的样式与运行环境。
- `meeting-dashboard.test.cjs`：业务口径测试。
- `scripts/sync-export.cjs`：将更新后的源代码同步到独立页面，不依赖原制作工具。

修改源代码后执行（Node.js 18+，不需要 npm install）：

```sh
npm run build
npm test
```

`index.html` 的导出标记与外围运行环境请保留；日常仅修改 `meeting-dashboard.html`。原对话内的设计选项是可选能力，普通浏览器不依赖它，业务筛选和展开功能可以独立使用。

## 本版业务边界

- 销售：签约、人工确认的净签约、开票、回款、当前商机金额。当前商机只统计确保 / 争取，不受月份筛选影响。
- 项目健康：期间人工预算与实际成本、截至期末的费用预算执行、延期节点。
- 公司经营：预计 / 实际确认收入及跨期差额、项目 / 闲置 / 运营 / 其他四类成本、闲置人员明细。
- 每个板块下方都有默认收起的“口径与待确认项”，说明算法、业务来源和未定事项。
- 运营成本算法、P 值规则、部分预算与确收口径仍需业务确认，不能将模拟结果视为法定财务报表或已落地的生产算法。

测试覆盖 45 组月份区间 × 4 个组织范围的汇总关系、跨期确收差额、人工确认净签约、四类成本不重复、折叠区默认关闭与日期边界。
