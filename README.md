# 梵行经营看板 · 会议版

用于确认经营看板的展示内容、计算口径和交互。包含销售、项目健康、公司经营三个板块，以及月份区间 / OP 组织筛选。

**全部是模拟数据，不连接飞书，不含会议原文、真实财务或人员数据、访问凭证。** 模拟覆盖 2026 年 1—9 月，默认展示 9 月完整月末场景，并非实时经营情况。

## 打开页面

公开访问地址：<https://sokripper.github.io/fanxing-business-dashboard/>。无需登录，也无需安装依赖。

也可以下载或克隆仓库后，直接使用现代浏览器打开 `index.html`。代码仓库和演示网页均为公开内容，请勿提交真实业务数据或访问凭证。

GitHub Pages 从 `main` 分支根目录发布。更新源代码后执行下方构建和测试，再将 `meeting-dashboard.html` 与更新后的 `index.html` 一起提交推送，网页会自动更新。

## 文件与维护

- `meeting-dashboard.html`：可编辑源代码，包含界面、模拟数据和计算函数。
- `index.html`：可独立打开的导出页面，保留原预览的样式与运行环境。
- `meeting-dashboard.test.cjs`：业务口径测试。
- `scripts/sync-export.cjs`：将更新后的源代码同步到独立页面，不依赖原制作工具。

修改源代码后执行（Node.js 18+，不需要 npm install）：

```sh
npm run build
npm test
```

`index.html` 的导出标记与外围运行环境请保留；日常仅修改 `meeting-dashboard.html`。原对话内的设计选项是可选能力，普通浏览器不依赖它，业务筛选和展开功能可以独立使用。

## 本版业务边界

- 销售：签约、人工确认的净签约、开票、回款、当前商机金额。当前商机只统计确保 / 争取，不受月份筛选影响。
- 项目健康：期间人工预算与实际成本、截至期末的费用预算执行、延期节点。
- 公司经营：预计 / 实际确认收入及跨期差额；成本构成按最新补充框架分为三组七项：成本下的项目费用，OP 费用下的运营费用 / 销售费用 / 财务税费，经营费用下的交付产研费用 / 管理费用 / 财务费用。
- 财务税费与财务费用分别使用独立模拟金额，按月份及 OP 筛选并计入各自小计和展示合计。取数来源、科目边界、计提算法与组织分摊规则待确认；当前不按确收金额的 7% 或其他比例计提，也不将未取到的数据填零。
- 闲置成本的科目归属尚待确认，暂列“待归属闲置”；展示合计 = 七项已分类费用 + 待归属闲置。右侧人员明细复用同一金额，不重复计算。此合计不代表公司全口径成本。
- 每个板块下方都有默认收起的“口径与待确认项”，说明算法、业务来源和未定事项。
- 科目完整定义、P 值规则、公共费用分摊到 OP 的方法、部分预算与确收口径仍需业务确认。新增科目金额及组织归属为独立模拟数据，未执行真实费用重分类，不能将模拟结果视为法定财务报表或已落地的生产算法。

测试覆盖 45 组月份区间 × 4 个组织范围的汇总关系、跨期确收差额、人工确认净签约、三组七项费用及闲置不重复、两项财务类科目的独立归集及筛选、折叠区默认关闭与日期边界。
